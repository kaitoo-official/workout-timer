# 実機確認手順（ビルド102）約10分

## ビルド102で直したこと
1. ロック画面に、終わった区間（「休憩 0:00」など）が溜まっていた → 区間が変わったら消えるように修正
2. アプリを開いている間、区間の切り替わりでチャイムが鳴らないことがあった → 鳴る直前の通知を消さないように修正
3. 「Edit」「Delete」が英語だった → 日本語（「編集」「削除」）に
4. 数字をキーボード（テンキー）でも入力できるように（− / ＋ も残しています）
5. 「動作記録（テスト用）」を追加。音が鳴らなかったときなどに、何が起きたかを後から確認できます
6. チャイムの音を変更（まだ仮。別案から選んでもらった音に、次のビルドで差し替えます）

## A. 更新（1分）
1. 「TestFlight」→「KAITOO 筋トレ検証」→「アップデート」。
2. 「ビルド 102」になっていることを確かめます。
3. 「筋トレタイマー」を開きます。

## B. 日本語と数字入力（2分）
4. メニュー画面の左上が「**編集**」になっているかを見ます。
5. 「テスト」の「**編集**」→「周回」の右の数字の枠をタップします。**数字のキーボード**が出るかを見ます。
6. 「2」と入力して、キーボードの上の「**閉じる**」を押します。「2周」になるかを見ます。
7. 「種目の間」の枠に「45」と入力 →「閉じる」。
8. 種目の「プランク」をタップ →「時間」の枠に「20」と入力 →「閉じる」→「決定」→「保存」。

## C. 終わった区間が消えるか（4分）
9. メニュー画面の一番下の「**動作記録（テスト用）**」→「**ログを消去**」→「閉じる」。
10. 「テスト」の「**開始**」→「**完了して次へ**」を押します（休憩が始まります）。
11. **すぐ電源ボタンでロック**し、画面をタップしてロック画面を出します（上にスワイプしません）。
12. 休憩 → プランク → 休憩 → 腹筋 と進む間、ロック画面の筋トレタイマーの枠が**いつも1つだけ**かを見ます（「0:00」の古い枠が残らないこと）。
13. 区間の5秒前に「ピッ×5」、0秒にチャイムが鳴るかを聞きます。
14. 「腹筋」の枠で「**完了**」を押します。
15. もう一度「テスト」を始め、今度は**アプリを開いたまま**最後まで進めます。区間の切り替わりのたびにチャイムが鳴るかを聞きます。

## D. 記録を送る（1分）
16. メニュー画面の「**動作記録（テスト用）**」→「**ログをコピー**」を押します。
17. このチャットに貼り付けます。
18. 一言メモ：古い枠は消えたか／チャイムが鳴らない時はあったか（あれば、だいたい何時何分か）
