# 実機確認手順 v5（iPhone 15 Pro / iOS 26.6.2・ビルド5のまま）

## これまでに分かったこと
- 1回目（ビルド1）：方式A（先読み）は切り替わらない。方式B（区間ごと予約）はロック中も予定どおり始まるが、同時5件まで。通知はロック中・YouTube全画面中に届く。
- 2回目（ビルド3）
  - ロック画面とDynamic Islandのボタン（完了・一時停止・再開・スキップ）は、アプリが裏にあっても効いた。
  - 予約した表示が始まった瞬間に、裏にいるアプリが少し動いた形跡がログにあった。
  - Dynamic Island が古い区間（0:00）を出していた → 新しい区間を優先するよう修正。
  - 方式C：行ごとのバーはアプリなしで進むが、これから始まる行の数字は「0:20」で止まったまま → 数字の出し方を修正。

- 3回目（ビルド4）
  - 予約した表示（B2〜B5）は、アプリを開かなくても予定どおり始まった（1〜3秒遅れ）。始まる瞬間にアプリも裏で少し動いた。
  - ただし裏での「補充」が最後まで終わらず、6区間目以降は出なかった。終わった区間は「0:00」で溜まり、最後は全部「終了」表示になった。
  - 音声（H）：聞こえる、動画の音は小さくなる、消音スイッチONでは鳴らない → 合格。本体では「ピッ」の機械音と、0秒でチャイムにする案。

- 4回目（ビルド5）
  - 予約した表示が始まる瞬間に、裏でアプリが30〜75ミリ秒だけ動き、終わった区間の表示を消せた → ロック画面には常に今の区間だけが出る。
  - 裏での新しい予約は「Target is not foreground」で拒否された → サーバーなしでは、最後にアプリかボタンを触った時点から4区間先までしか自動で進めない。

## v5 の確認：ロック画面の「完了」で先の予約を補充できるか（約3分・録画してOK）
始める前に「ログを消去」。**最後までアプリを開かないこと。**

1. アプリで、方式「B: 区間ごと予約」、予定「**回数制まじり**」を選ぶ。
2. 「通知許可を確認して検証開始」→ すぐ電源ボタンでロック。
3. 20秒後に「2/8 腕立て伏せ 10回」が出たら、その枠の「**完了**」を押す（顔認証だけ通し、ロック画面のまま）。
4. そのあと「3/8 休憩 → 4/8 プランク → 5/8 休憩 → 6/8 スクワット」と、自動で続くか見る。
5. 「6/8 スクワット」で「完了」→「7/8 休憩」→「8/8 レッグレイズ」で「完了」→ 終了。
6. 画面収録を止め、アプリを開いて「ログをコピー」。

見たいこと：完了を押した後に「予約LA失敗 … Target is not foreground」が出ないか。休憩→プランク→休憩→スクワットが自動で出るか。
