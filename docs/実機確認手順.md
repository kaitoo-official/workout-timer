# 実機確認手順 v6（iPhone 15 Pro / iOS 26.6.2・ビルド6）

これまでの結果は README.md の「実機結果」にまとめています。

## v6 で変えたこと
- アプリが前面にあるときは、今までどおり区間ごとの表示を4つ先まで予約します（見出しが切り替わる表示）。
- **ロック画面のボタンを押したとき**は、1つの表示に「休憩 → プランク → 休憩 → スクワット」を**行で並べる**ようにしました（まとめ表示）。
  - 今の区間は、**バーが減っている行**です。
  - 右の数字は「その行が終わるまでの時間」です。今の区間の行は、残り時間と同じになります。
  - ボタンは「一時停止」と「完了・次へ」です。

## 確認手順（約5分）

### A. ビルド6にする（1分）
1. iPhoneのホーム画面で、オレンジ色の「**TestFlight**」をタップします。
2. 「**KAITOO 筋トレ検証**」をタップします。
3. 「**アップデート**」が出ていれば押して、完了まで待ちます。
4. 「**ビルド 6**」（または「1.0 (6)」）になっていることを確かめます。
5. ホーム画面に戻ります。

### B. アプリの準備（1分）
6. 「**筋トレ検証**」を開きます。
7. 「進行中」の枠と赤い「**検証を終了**」があれば押します。
8. 画面を上にスクロールして一番下へ行き、青い「**ログを消去**」を押します。
9. 下にスクロールして、一番上に戻ります。

### C. 画面収録を始める（30秒）
10. 画面の**右上の角から下へ**スワイプして、コントロールセンターを開きます。
11. **白い丸に赤い点**のボタンをタップします。「3・2・1」のあと録画が始まります。
12. 何もない所をタップして、コントロールセンターを閉じます。

### D. 開始（30秒）
13. 「開始」の枠で、次の2つを選びます。
    - 1段目：「**B: 区間ごと予約**」
    - 2段目：「**回数制まじり**」
14. 青い「**通知許可を確認して検証開始**」を押します。
15. 「1/8 休憩 0:20」になったら、**すぐ電源ボタンを1回押して**画面を消します。

### E. ロック画面で操作（約3分）　※最後までアプリを開かないでください
16. 画面をタップしてロック画面を出します。顔認証で鍵が開いても、**上にスワイプしません**。
17. 約20秒後に「**2/8 腕立て伏せ　10回**」が出ます。枠の「**完了**」を押します。顔認証を求められたら、認証だけ通します。
18. **ここが今回の山場です。** 枠が次のような「まとめ表示」に変わるかを見ます。

    ```
    3 休憩            ━━━━━  0:20
    4 プランク        ━━━━━  0:40
    5 休憩            ━━━━━  1:00
    6 スクワット              10回
    [一時停止] [完了・次へ]
    ```

19. そのまま約1分見ます。次のように進めば成功です。
    - 最初の20秒：「3 休憩」のバーが減り、数字も減る
    - 次の20秒：「4 プランク」のバーが減り、数字が残り時間になる
    - 次の20秒：「5 休憩」のバーが減る
    - そのあと：休憩のバーがすべて空になり、「6 スクワット 10回」が残る
20. 区間の5秒前に「5秒前：次は○○」の通知が来るかも見ます。
21. 「6 スクワット」の番になったら、「**完了・次へ**」を押します。
22. 「7 休憩」と「8 レッグレイズ」のまとめ表示に変わるかを見ます。休憩のバーが空になったら、もう一度「**完了・次へ**」を押します。表示が消えれば終了です。
23. 途中で止まったり、表示が消えたりしたら、無理に続けずにFへ進んでください。それも大事な結果です。

### F. 終わらせる（1分）
24. 画面の**右上から下へ**スワイプし、**赤い画面収録ボタン**をタップして録画を止めます。
25. ロックを解除して「**筋トレ検証**」を開き、下の「**ログをコピー**」を押します。

### G. 送るもの
26. このチャットに**ログを貼り付け**ます。
27. 動画を `ダウンロード\Mobile Devices` に移し、`@` で添付します。
28. 次の4つを一言ずつ書きます。
    - まとめ表示に変わったか
    - 今どの区間か、バーで分かったか
    - 数字の動きは分かりやすかったか、分かりにくかったか
    - このまま本番で使えそうか（見た目の感想で大丈夫です）
