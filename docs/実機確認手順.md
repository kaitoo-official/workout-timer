# 実機確認手順 v2（iPhone 15 Pro / iOS 26.6.2）

## 1回目（ビルド1、2026-10-17）で分かったこと
- 方式A（先読み）：区間が終わっても表示は「前の区間 0:00」のまま。先読みへの切替は起きなかった → 不合格。
- 方式B（区間ごと予約）：ロック中でもOSが予定時刻に次の区間の表示を出した（例：4/8 は予定どおり 0:15 から開始）→ 自動切替は可能。
  ただし、予約中も含めて同時に存在できるのは5件まで。終わった区間の表示は残るので、ロック画面が縦に積み重なる。
- 通知（5秒前・開始）は、ロック中にも YouTube 全画面中にも届いた。
- 画面収録中は Dynamic Island が録画の赤丸になり、表示を判定できなかった。
- Live Activity のボタン（一時停止・スキップ・完了）は、まだ試していない。

## v2 の変更点（ビルド3）
- 方式C「予定表」を追加：1つの表示に次の数区間を並べ、各行のタイマーとバーがOSの時計で減っていく。アプリの更新がなくても、減っている行が今の区間になる。
- 予定「回数制まじり」を追加：休憩 → 腕立て10回 → 休憩 → プランク20秒 → 休憩 → スクワット10回 → 休憩 → レッグレイズ10回（実際のメニューに近い形）。
- ログに「アプリ起動（バックグラウンド）」「LA状態の変化」を追加：ロック画面のボタンでアプリが裏で動いたかが分かる。
- 方式Bの予約は5件までにした。

## 確認（約20分）。録画は止めて、気づいたことはメモかスクリーンショットで
各テストの前に「ログを消去」、終わったら「ログをコピー」してチャットへ。

### テスト1：方式B ×「回数制まじり」（一番大事）
1. 方式B、予定「回数制まじり」で開始 → すぐロック。
2. 腕立て（2区間目）が出たら、**ロック画面の「完了」を押す**（アプリは開かない。Face ID で解除が求められたら解除だけしてロック画面のまま）。
3. その後も休憩・プランク・休憩・スクワットと進むか見る。スクワットでも「完了」をロック画面から押す。
4. 見ること：完了ボタンが効いたか／押した後に次の休憩が自動で始まるか／終わった区間の表示が消えるか。
5. 途中で一度だけ YouTube を再生し、Dynamic Island を長押しして中身とボタンを見る。

### テスト2：方式C ×「時間制の連続」
1. 「検証を終了」→ ログ消去 → 方式C、予定「時間制の連続」で開始 → ロック。
2. 見ること：予定表の行のうち、今の区間の行だけ数字とバーが減っていくか。何行目まで正しく進むか（4行まで表示）。

### テスト3：ボタン操作と通知の取消（F）
1. 方式C で開始 → ロック画面の「一時停止」→ 30秒待つ：5秒前の通知が来ないこと。
2. アプリを開いて「再開」→ ロック画面の「スキップ」→ 古い予定の通知が重ならないこと。
3. アプリで「検証を終了」→ 1分待つ：通知も表示も残らないこと。

### 音声（H）：どれかのテスト中に1回でよい
- YouTube を音ありで再生中に「ご・よん・さん・に・いち」が聞こえたか、動画の音は小さくなったか止まったか。
- 消音スイッチ（アクションボタン）ON のときはどうか。

### 許可の表示が出たら
ロック画面に「ライブアクティビティの許可を継続しますか？」と出たら「常に許可」を選んでください。
