# 実機確認手順（iPhone 15 Pro / iOS 26.6.2）

所要 約30分。各テストの前にアプリ内「ログを消去」、終わったら「ログをコピー」してチャットへ貼る。
画面ロックは電源ボタン。YouTube は音ありで再生しておく。

## 0. 準備（初回のみ）
1. iPhone に「TestFlight」アプリを入れ、メールの招待（KAITOO 筋トレ検証）から「インストール」。
2. 設定 → 筋トレ検証 → 通知：オン、ライブアクティビティ：オン。
3. 消音スイッチ（アクションボタン）と集中モードはオフで開始。状態を記録。

## 1. 方式A（1つのLA＋先読み）
1. 方式「A」を選び「検証開始」→ 通知を許可。
2. すぐホームへ → YouTube で動画を再生（1分ほど）→ 画面ロックして残り時間を見る。
3. 見ること：
   - Dynamic Island（YouTube中）とロック画面に、種目名・残り時間・ボタンが出るか（C）
   - 5秒前の「ご・よん・さん・に・いち」と開始通知が届くか、動画音声はどうなるか（D・H）
   - **アプリを開かずに**、表示の種目名が「休憩→プランク→休憩→…」と切り替わるか。何区間目で止まるか（E）
   - 腕立て（8区間目）で止まり、勝手に完了しないか（G）
4. 約3分後にアプリを開き、ログをコピー（復帰時の記録が「表示:何番目」かが判定材料）。

## 2. 方式B（区間ごと予約LA）
1. アプリで「検証を終了」→ ログ消去 → 方式「B」で開始。
2. 1と同じく YouTube → ロック。
3. 見ること：区間ごとに新しい表示が自動で出るか、古い表示が「終了」で残るか、Dynamic Island がどれを出すか、アラートの出方。
4. 約3分後にアプリを開き、ログをコピー。

## 3. 操作と通知の取消（F）
1. 方式Aで開始 → ロック画面のLAで「一時停止」→ 30秒待つ：通知が鳴らないこと。
2. 「再開」→ 次の区間で「スキップ」：古い予定の通知が重複しないこと。
3. アプリで「検証を終了」→ 1分待つ：通知もLAも残らないこと。
4. ログをコピー。

## 4. 追加で分かれば記録
- 消音スイッチONにしたときの5秒前音声
- アプリスイッチャーで上にスワイプして強制終了した場合（通常の切替とは分けて記録）

## チャットに送るもの
テストごとに：ログ（コピーしたもの）＋「Eで何区間目まで自動で切り替わったか」「音声と動画音」「気になった表示」。
スクリーンショットや画面収録があればなお良い。
