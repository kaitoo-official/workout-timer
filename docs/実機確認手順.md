# 実機確認手順 v3（iPhone 15 Pro / iOS 26.6.2）

## これまでに分かったこと
- 1回目（ビルド1）：方式A（先読み）は切り替わらない。方式B（区間ごと予約）はロック中も予定どおり始まるが、同時5件まで。通知はロック中・YouTube全画面中に届く。
- 2回目（ビルド3）
  - ロック画面とDynamic Islandのボタン（完了・一時停止・再開・スキップ）は、アプリが裏にあっても効いた。
  - 予約した表示が始まった瞬間に、裏にいるアプリが少し動いた形跡がログにあった。
  - Dynamic Island が古い区間（0:00）を出していた → 新しい区間を優先するよう修正。
  - 方式C：行ごとのバーはアプリなしで進むが、これから始まる行の数字は「0:20」で止まったまま → 数字の出し方を修正。

## v3 の確認（約10分）。録画してOK（Dynamic Islandは長押しの時だけ録画を止めると見やすい）
各テストの前に「ログを消去」、終わったら「ログをコピー」して貼る。**途中でアプリを開かないこと**が大事です。

### テスト1（最重要）：方式B ×「時間制の連続」
8区間のうち7区間が自動で進む予定なので、5件の上限を超えます。
1. 方式B、予定「時間制の連続」で開始 → すぐロック（または YouTube）。
2. **約3分、アプリを開かずに待つ。** 最後の腕立てまで、表示が自動で切り替わり続けるかを見る。
3. 見ること：
   - 区間が変わるたびに、終わった区間の表示が消えるか（ロック画面に溜まらないか）
   - 6区間目（サイドプランク左）以降も表示が出るか
   - Dynamic Island が今の区間を出しているか
4. 腕立てでロック画面の「完了」→ 終了。アプリを開いてログをコピー。

### テスト2：方式C ×「時間制の連続」
1. 「検証を終了」→ ログ消去 → 方式C、予定「時間制の連続」で開始 → ロック。
2. 約1分半、アプリを開かずに見る：今の区間の行だけ数字が減り、バーが短くなるか。2行目・3行目の数字も、その区間が始まったら正しく減るか。
3. 終わったらアプリを開いてログをコピー。
