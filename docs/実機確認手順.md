## v4 の確認（テスト1だけ。約3分。録画してOK）
始める前に「ログを消去」、終わったら「ログをコピー」して貼る。**途中でアプリを開かないこと**が大事です。

### テスト1：方式B ×「時間制の連続」
8区間のうち7区間が自動で進む予定なので、5件の上限を超えます。
1. 方式B、予定「時間制の連続」で開始 → すぐロック（または YouTube）。
2. **約3分、アプリを開かずに待つ。** 最後の腕立てまで、表示が自動で切り替わり続けるかを見る。
3. 見ること：
   - 区間が変わるたびに、終わった区間の表示が消えるか（ロック画面に溜まらないか）
   - 6区間目（サイドプランク左）以降も表示が出るか
   - Dynamic Island が今の区間を出しているか
4. 腕立てでロック画面の「完了」→ 終了。アプリを開いてログをコピー。

見たいこと：ログに「補充：B5を予約」「補充：B6を予約」…が出るか、腕立てまで表示が切り替わり続けるか、ロック画面に古い表示が溜まらないか。
