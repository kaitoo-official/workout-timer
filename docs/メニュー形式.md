# メニューのデータ形式（v1）

iOS 版の保存形式です。将来の Android 版でも同じ JSON を読み書きできるよう、言語に依存しない形で定めます。
実装：`Packages/WorkoutCore/Sources/WorkoutCore/Menu.swift`

## ファイル
端末内の Application Support/workout-timer/ に保存します。

| ファイル | 中身 |
|---|---|
| `menus.json` | `{ "schemaVersion": 1, "menus": [Menu, ...] }` |
| `session.json` | 進行中のセッション（無ければファイルなし）。形式は 動作ルール.md の「保存」 |
| `settings.json` | 音・触覚の設定 |

- 文字コードは UTF-8、日時は ISO 8601（UTC、例 `2026-10-17T05:04:28Z`）、時間は**秒の整数**。
- 書き込みは一時ファイル→置き換えで行い、途中で落ちても壊れたファイルが残らないようにします。
- 読み込み時に `schemaVersion` が新しすぎる場合は、上書きせずに読み込みエラーとして扱います。

## Menu
```json
{
  "id": "6C1E5B7A-0F43-4C5E-9E0B-2D1C3A4B5C6D",
  "name": "CHEST",
  "rounds": 3,
  "restBetweenExercises": 60,
  "restBetweenRounds": 90,
  "autoStartTimed": false,
  "exercises": [
    { "id": "…", "name": "ノーマル", "amount": { "type": "reps", "value": 15 } },
    { "id": "…", "name": "プランク", "amount": { "type": "seconds", "value": 30 }, "restAfterOverride": 15 }
  ]
}
```

| 項目 | 型 | 範囲 | 意味 |
|---|---|---|---|
| `id` | UUID 文字列 | — | 一意な識別子 |
| `name` | 文字列 | 1〜40文字 | メニュー名 |
| `rounds` | 整数 | 1〜20 | 全体を何周するか |
| `restBetweenExercises` | 整数（秒） | 0〜1800 | 種目と種目の間の休憩（左右の種目の間も同じ） |
| `restBetweenRounds` | 整数（秒） | 0〜1800 | 周の最後の種目の後の休憩 |
| `autoStartTimed` | 真偽 | — | 時間制の種目を休憩の後に自動で始めるか |
| `exercises` | 配列 | 1〜50件 | 上から順に1種目ずつ実施する |

## Exercise
| 項目 | 型 | 範囲 | 意味 |
|---|---|---|---|
| `id` | UUID 文字列 | — | 一意な識別子 |
| `name` | 文字列 | 1〜40文字 | 種目名。左右は別の種目として登録する（例「ブルガリアンスクワット右」） |
| `amount.type` | `"reps"` / `"seconds"` | — | 回数制／時間制 |
| `amount.value` | 整数 | 回数 1〜999、秒 1〜3600 | 運動量 |
| `restAfterOverride` | 整数（秒）または省略 | 0〜1800 | この種目の後の休憩だけを置き換える。**周の最後の種目では使わず、周回間休憩を優先する** |

休憩が0秒の場合、その休憩は区間として作りません。
